# CareerPilot User Guide

## Morning

1. Open the dashboard.
2. Review follow-ups and ready-to-apply jobs.
3. Run Job Search or review the Daily Digest.

## Selecting jobs

Prioritize fresh jobs with suitable experience requirements and strong skill matches. Save or queue only jobs you would genuinely apply to.

## Preparing an application

Use the selected job context to capture the full JD. Run One-Click Optimizer or Resume Intelligence. Review every generated document before using it.

## Applying

Open the official job page and submit manually. Never submit unverified information.

## Tracking

After applying, update Auto Apply Assistant and Application CRM. Record recruiter contact and future follow-up dates.

## Follow-ups

Complete due follow-ups before adding too many new applications. Update the CRM stage when a recruiter responds.

## Weekly review

Use the dashboard and Career Coach to review response rate, source performance, recurring skill gaps, and pending applications.
